# SQL Practice

Hands-on SQL practice using supply chain and logistics scenarios. All code is written in SQL Server (T-SQL) syntax.

## Topics covered so far
- DDL: CREATE, ALTER, DROP
- DML: INSERT, UPDATE, DELETE
- Filtering: WHERE, comparison, logical, range, membership and search operators
- Aggregation: GROUP BY, HAVING, DISTINCT, ORDER BY, TOP

## How to use
Open a scenario folder, run `setup.sql` once to build the table and load the data, then work through the questions in its README. My answers are in `solutions.sql`.
